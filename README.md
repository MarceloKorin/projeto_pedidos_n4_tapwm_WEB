Painel de gestão desenvolvido em **React + Vite** exclusivo para usuários com perfil `admin`.

## Funcionalidades
- Autenticação segura com validação de perfil administrativo (`perfil === 'admin'`).
- Dashboard com indicadores em tempo real (Total de Pedidos, Pedidos Pendentes e Faturamento).
- Visualização detalhada de cada pedido: **quem pediu** (nome e e-mail), **o que pediu** (lista de produtos, quantidades e subtotais), **observações** e **valor total**.
- Alteração rápida de status (`Pendente` -> `Em Preparo` -> `Concluído`).
- Gestão de catálogo para adicionar novos produtos sincronizados com o App Mobile.
